# shift-spa

アルバイトのシフト表を作るWebページです。期間とメンバーを入れると、シフトを自動で割り振ります。

## 開き方

- **Webで開く**: https://crazykohei0123.github.io/shift-spa/ を開きます。
- **ファイルで開く**: リポジトリをダウンロード (Code → Download ZIP) して、`index.html` をブラウザで開きます。

## 使い方

1. **期間とシフト枠を入れる**: 開始日と終了日を選び、シフト枠 (名前・時間帯・人数・責任者の人数) を足します。持ち場 (キッチン・ホールなど) もここで増やせます。
2. **メンバーと希望を入れる**: 名前を足し、日ごとの出勤可能な時間帯 (例: 9:00〜17:00、空=終日可) を入れます。丸一日ダメな日は「休」ボタンで休みにします。責任者の人には「責」にチェックを入れます。
3. **シフトを作る**: 「自動作成」ボタンを押すと、休み・希望時間をよけて人数が足りるように割り振ります。セルの × で外す・選んで足す、で微調整できます。

## 出力のしかた

- **PNG出力**: 結果の表を画像で保存します。パソコンでは自動でダウンロード、スマートフォンでは共有シートまたはプレビューからの長押しで保存します。
- **CSVコピー**: 結果の表をクリップボードにコピーします。
- **印刷**: ブラウザの印刷機能で印刷できます。

## 入れた内容の保存場所

入力した期間・メンバー・シフトは、使っているスマートフォンやパソコンなどの端末の中にだけ保存されます。クラウドは使っていません。

## 割り振りの考え方

日付の順番に1回ずつ決めます。休みの人・希望時間と重ならない人は外し、責任者枠には責任者を入れ、回数が少ない人・重なりが大きい人・前日に働いていない人を優先します。足りない枠は赤字で「要N」と出ます。

## 中身 (開発者向け)

- `index.html` — 画面の骨組み
- `css/style.css` — 表の見た目と印刷用の指定
- `src/app.ts` — 動きのプログラム (TypeScript)
- `js/app.js` — `src/app.ts` を変換したもの (`npm run build` で作ります)
- `tests/` — 動きの確認テスト (`npm test` で実行します)

開発を続けるときは `npm install` のあと、`npm run build` で変換、`npm test` で確認します。
